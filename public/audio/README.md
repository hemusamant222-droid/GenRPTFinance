# GenRPT Finance instrumental bed

`genrpt-tech-bed.mp3` is an original, procedurally synthesized 33-second instrumental made for this demo. It uses no external recordings or samples. Tempo: 112 BPM; stereo; normalized to approximately -23 LUFS with opening and closing fades.

Regenerate the source WAV with `python scripts/create-tech-music.py`, then use FFmpeg loudness normalization and MP3 encoding as required. The finished music version preserves the original full-size video stream without re-encoding. No voiceover is included.
